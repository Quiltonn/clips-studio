**Новое**
- Обход блокировок YouTube: если YouTube напрямую не открывается, программа сама подбирает способ обхода и скачивает видео по ссылке без VPN (только для этой программы). Настройки → «Сеть», включено по умолчанию
- Поле «Прокси» в Настройках → «Сеть»: можно указать локальный прокси VPN-клиента, и через него пойдёт только скачивание в программе
